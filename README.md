# Мишна Брура со сносками Ялкут Йосеф

Копия сайта «Мишна Брура — русское издание» с дополнительным слоем «Ялкут Йосеф» (законы и сноски к главе).
Оригинал (bu3142-lgtm/mishna-berura) не изменяется: отсюда в него ничего не отправляется.

- `contentN.json` — главы Мишны Бруры, копируются из оригинала без изменений.
- `yalkut/index.json` — какие блоки «Ялкут Йосеф» относятся к какой главе; `yalkut/<id>.json` — сами блоки.
- `original-manifest.json` — версия оригинала и контрольные суммы глав (для команды «обнови»).
- `tools/build_yalkut.py` — перенос блоков из yalkutIosef_all.html с проверкой; `docs/` — таблицы соответствия глав.
